# Landing lab character GLBs

Generated by `scripts/export-landing-characters.py` (PlayerMale, PlayerFemale, NpcWorker, shared `animations.glb`) and
`scripts/export-landing-npcs.py` (seven NPCs skinned to the NpcWorker Mixamo skeleton with Blender automatic weights, with a
nearest-surface weight transfer when heat weighting fails). Sources live in `artifacts/characters/` at the workspace root.
Used only by the dev page `/demo/landing-lab`. Known issue: arm/hand poses in the walk and jog clips look wrong on the
non-PlayerMale rigs; rig and clip retargeting is being handled separately.
