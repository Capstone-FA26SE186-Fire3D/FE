# Fire3D visual asset provenance

`fire3d-concrete.png` is a concept texture generated with the Codex `imagegen` skill on 2026-09-15. Retained as a visual reference; the current runtime does not load it.

`landing-opening-v2.webp` and `landing-cutaway-v2.webp` are captures from the actual Three.js canvas, with DOM overlays hidden while capturing. They are fallback imagery, not evidence of active WebGL. The cutaway was refreshed on 2026-09-16 with the connected/opened facade and distributed room fires. Recapture both after final visual acceptance.

The interactive building, fire, smoke, lighting, paint and camera are procedural Three.js code. User-supplied real-fire photos are visual references only, not bundled assets.

The `-v2` posters were recaptured on 2026-10-21 from the circular glass landing scene (`/demo/landing-lab`, 1600x900, dev overlays removed). The file names carry a version suffix because static assets are cached by the CDN for a day: change the suffix whenever the image changes.
